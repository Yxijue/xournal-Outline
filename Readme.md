# PageOutline 1.9.6

为 Xournal++ 扩展多级大纲与书签功能，并提供分类笔记库，统一管理多份 .xopp 笔记。支持快速预览库内笔记的大纲，实现笔记内定位与跨笔记跳转。

**安装请下载[本仓库 Release](https://github.com/Yxijue/xournal-Outline/releases/latest) 中的完整 Windows 插件包。** 仓库文件用于查看源码，不包含两个 EXE 及其运行库；直接下载源码 ZIP 不能替代完整安装包。

Xournal++ 页面大纲、独立书签和跨笔记分类库插件，附带 Windows 64 位独立大纲窗口与 PDF 书签工具。

插件从笔记中的文字标题建立三级大纲，在独立树形窗口内跳转、调整层级；支持分类管理多份 `.xopp` 笔记，并一键导出带真正多级书签的 PDF。这里的大纲窗口独立于 Xournal++ 左侧原生目录树。

## 1. 安装与更新

### 安装条件

插件基于 Xournal++ 1.3.8 若使用老版本可能会报错

### 安装位置

将压缩包中的整个 `PageOutline` 文件夹放到：

```text
Xournal\share\xournalpp\plugins\PageOutline
```

最终结构示例：

```text
Xournal\
├─ bin\xournalpp.exe
├─ share\xournalpp\plugins\PageOutline\
│  ├─ plugin.ini
│  ├─ main.lua
│  ├─ Readme.md
│  ├─ Outline-Tree.exe
│  ├─ Outline-Tree-runtime\
│  ├─ PDF-Bookmarks.exe
│  ├─ PDF-Bookmarks-runtime\
│  └─ 配套 Python 源文件
├─ PageOutline\             ← 首次使用后生成的数据目录
│  ├─ navigation.json
│  ├─ tree-preferences.json
│  └─ cache\
└─ Notes\                   ← 分类文件夹与托管笔记
   ├─ 未分类\
   └─ 自建分类\子分类\
```

启动 Xournal++，在“插件 → 插件管理器”中启用 PageOutline；必要时重启软件让插件加载。`plugin.ini` 默认不自动启用，需要在插件管理器启用一次。

更新已有版本时，在关闭程序后覆盖插件文件。保留自己的 `Xournal\PageOutline` 数据目录和 `Xournal\Notes` 笔记目录。旧的“使用说明.md”可以删除，本版统一使用 `Readme.md`。

两个 EXE 必须分别与对应的 `*-runtime` 文件夹放在一起。不要只复制 EXE，也不要删除运行库中的文件。本包是完整插件包，未附带个人笔记、书签、窗口偏好或通信缓存。

## 2. 快速开始

1. 按 **Ctrl+Shift+F8** 打开/刷新独立大纲窗口，点击标题跳到对应页面。
2. 想按分类管理笔记时，在“笔记库 → 分类库”中创建分类并导入笔记。导入会复制笔记，后续从库中打开的是副本。
3. 需要 PDF 大纲时，使用“插件 → 导出带大纲的 PDF”，选择输出位置即可。

## 3. 标题识别与多级大纲

### 标题格式

每个标题使用一个普通文字框，其第一行以 1～3 个 `#` 和至少一个空白字符开头：

```text
# 第一章
## 第一节
### 一个知识点
```

- `#`、`##`、`###` 分别对应一级、二级、三级。
- 标题按页面顺序，同页按纵坐标、横坐标排序；最近的较低级标题作为父项。
- 支持中文、重复标题以及不同图层中的文字标题。
- 只识别文字，不进行手写 OCR。四级及以上标题不纳入大纲。
- 笔记里的 `#` 标记会作为正文文字保留；独立大纲和 PDF 书签显示标题名称。

### 当前笔记模块

“当前笔记 → 大纲”显示当前 Xournal++ 文档的标题树：

- 单击标题或选中后按 Enter，跳到对应页面；点左侧箭头只展开/折叠。
- “展开”“折叠”批量控制当前树。
- 搜索标题时保留父级，自动展开匹配结果；“清除”恢复完整大纲。
- 选中标题后点“1级”“2级”“3级”，或右键选择层级，修改当前笔记里对应文字标题的 `#` 数量。
- 层级修改会影响笔记正文与下次导出的 PDF 大纲，应保存笔记；可使用 Xournal++ 的撤销功能。
- 查看书签时，标题修改控件禁用。

大纲标题及层级保存在 `.xopp` 正文中。独立窗口的展开状态、选中项和滚动位置保存在窗口偏好中，按笔记区分；最多保留 50 份笔记的视图偏好。

### 插件菜单辅助操作

- **插入1/2/3级标题模板**：在当前页插入可编辑文字模板。模板可能与原笔记重叠，可用选择工具移动。
- **在当前页插入目录文字**：把当前标题和页码生成普通目录文字，建议在空白页操作。它是静态快照，不带点击链接；标题或页码变化后需重新生成。过长目录会提示超出一页空间。

这些插入操作可用 Ctrl+Z 撤销。

## 4. 独立书签

“当前笔记 → 书签”用于收藏阅读位置，与正文标题大纲分开保存；列表可以包含不同笔记的书签。

1. 保存当前笔记，在 Xournal++ 中停留到希望收藏的页面。
2. 选择书签分类：普通、待复习、重要例题或上次阅读。
3. 点“收藏当前页”。插件查询当前页后，输入书签名称。
4. 双击书签、按 Enter，或点“打开选中书签”，打开相应笔记并跳到保存页码。

支持改名和删除。删除书签仅删除导航记录，不删除正文。书签不会插入页面文字，也不会改变标题层级。

书签保存在 `navigation.json`，没有嵌入 `.xopp`，目前收藏的是页面而非精确坐标。插入、删除或重排页面后，旧页码不会自动跟踪内容，需要重新收藏。独立书签不会加入 PDF 导出；PDF 书签来自正文标题。

## 5. 分类笔记库与跨笔记导航

### 分类和笔记副本

“笔记库 → 分类库”的树形结构为：

```text
我的笔记库 → 分类 → 子分类 → 笔记 → 一级标题 → 二级标题 → 三级标题
```

- 分类对应 `Xournal\Notes` 下的实际子文件夹，文件夹使用分类图标，笔记使用文档图标。
- 选中分类后“新建分类”在其下创建子分类；选中“我的笔记库”创建顶层分类。
- “导入笔记”可选多份 `.xopp`，复制到选中分类；未选分类时复制到“未分类”。同名文件加编号，不覆盖已有文件。
- 导入副本后，相关导航记录会指向副本。后续打开和修改副本，原文件不会同步更新。导入已位于目标分类中的笔记时直接使用该文件。
- 每份笔记实际位于一个文件夹，暂不支持一份笔记同时属于多个虚拟分类。

### 浏览、搜索和整理

- 双击笔记打开笔记；双击标题打开笔记并跳到记录页码。选中后按 Enter 也可打开。
- 双击分类展开/折叠；“展开全部”“折叠全部”控制库内树形浏览。
- 搜索分类名、笔记名、标题，以及书签名称/标签。结果保留上级结构。
- 选中笔记或它的标题后“移动到分类”，或拖动到目标分类，会移动整份笔记文件并更新相关导航记录。
- 右键分类或笔记可重命名、打开所在文件夹。
- “移除分类（保留文件）”删除空文件夹；非空分类整体收纳到“未分类”下，保留子目录与附件，同名收纳目录加编号。
- “移出库”隐藏笔记索引，保留文件及书签；自动扫描不会将隐藏路径重新加入。再次通过“导入笔记”可取消隐藏。
- 当前打开的笔记及其所属分类，整理前需先保存并切换到其他笔记。根目录和“未分类”受到保护。

### 自动发现与索引

可在资源管理器中直接把分类、子分类、空文件夹和 `.xopp` 放入 `Notes`，工具会后台发现，不必再导入复制一次。

- 启动时后台检查；分类库可见期间约每 3 秒检查。快速切换/焦点变化复用最近的扫描。
- “同步文件夹”立即请求后台扫描，并强制重建标题索引。
- 常规扫描只解析新增或大小/修改时间变化的文件。搜索使用已有索引；标题编辑后先保存，库内索引才会更新。
- 复制未完成或损坏的文件会跳过并稍后重试，底部显示同步状态。
- 在 `Notes` 内改名或移动笔记，会用文件标识同步书签、最近阅读、返回记录和视图偏好；唯一内容指纹辅助识别复制后删除原件的情况。多个相同副本存在歧义时不会自动关联。
- 移到 `Notes` 外的文件不在自动扫描范围，需要重新导入。

导入复制的是 `.xopp` 文件本身，内嵌图片一并保留。外部 PDF 背景或其他外部依赖不会自动复制，需要自行保留并检查引用路径。

## 6. 最近阅读与返回

“笔记库 → 最近阅读”保留最近 30 份笔记及最近查询到的页码，双击、按 Enter 或点按钮恢复阅读位置。

顶部“返回”恢复从笔记库、独立书签或最近阅读发起导航前的位置，最多保存 50 条记录。跳转前先查询当前位置，只在确认目标成功打开后更新返回栈。跨笔记打开沿用 Xournal++ 的未保存确认，不会静默保存或丢弃编辑。

确认保存/取消后，如果显示尚未同步，回到独立窗口或点击“刷新”。最近阅读在打开、刷新、收藏或导航查询时更新；手动滚动不会逐帧记录。当前笔记大纲内的普通标题点击暂不加入返回栈。

## 7. 一键导出带多级书签的 PDF

在 Xournal++ 使用 **“插件 → 导出带大纲的 PDF”**：

1. 插件读取当前标题，导出包含背景的完整文档，每个笔记页对应一个 PDF 页。
2. 配套工具自动写入真正的三级 PDF 书签，并设置书签目标页和标题附近的纵向位置。
3. 校验书签名称、目标页和页数后，生成所选的最终 PDF，无需再手动运行工具。

中文标题和中文输出文件名受支持。已有输出文件时询问是否覆盖；新文件校验通过后才替换旧文件。取消覆盖保留原 PDF。

在 Acrobat 或支持 PDF 大纲的阅读器中打开书签面板即可跳转；将带书签的 PDF 打开到 Xournal++，也可查看其原生 PDF 大纲。当前 `.xopp` 的原生左侧目录树不会因此增加大纲。

Xournal++ 原来的普通“导出 PDF”不会自动调用本插件，应使用插件的导出菜单。无标题时会提示先添加标题。独立书签不参与此导出。

`PDF-Bookmarks.exe` 也可单独处理带对应 `.outline.tsv` 标题清单的 PDF；没有清单的普通 PDF 不会自动识别标题。一般使用插件的一键导出即可。
